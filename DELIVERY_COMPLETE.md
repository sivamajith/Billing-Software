## 🚀 How to Get Started

### Step 1: Installation (5 minutes)
```bash
cd c:\billling project\backend
npm install

cd ../frontend
npm install
```

### Step 2: Configuration (2 minutes)
Update `.env` files with:
- MongoDB connection string
- JWT secret
- API URL

### Step 3: Start Services (2 minutes)
```bash
# Terminal 1
cd backend
npm run dev

# Terminal 2
cd frontend
npm start
```

### Step 4: Access Application (1 minute)
- Frontend: http://localhost:3000
- Backend: http://localhost:5000/api

### Step 5: Login & Test (5 minutes)
Use provided test accounts to explore features
